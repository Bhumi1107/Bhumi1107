# Hi, I’m Bhumi 👋

I study AI and data science. I build tools that let you explore the evidence behind a result, whether that’s a missing value in a dataset or a word that influenced a prediction. The projects below run in your browser.

### DataProof Lab

What changes when you clean a dataset? Load the sample CSV, preview removing a duplicate, and compare the original and cleaned summaries side by side. You can see exactly which numbers change before deciding what to do with your data.

In the six-row sample, three cells are blank and one row appears twice. Removing the duplicate and filling the missing score with the median brings completeness from **90% to 92%**. Two blanks remain in the contact column.
