# Hi, I’m Bhumi 👋

I study AI and data science. I build tools that let you explore the evidence behind a result, whether that’s a missing value in a dataset or a word that influenced a prediction. Both projects below run in your browser.

### DataProof Lab

What changes when you clean a dataset? Load the sample CSV, preview removing a duplicate, and compare the original and cleaned summaries side by side. You can see exactly which numbers change before deciding what to do with your data.

[Explore DataProof Lab →](https://github.com/Bhumi1107/DataProof-lab)

### RepoSense AI

What makes a GitHub issue sound like a bug or a feature request? Try a sample issue to see its predicted label and the words that influenced it. Correct the label and the local Naive Bayes model learns from your feedback.

[Explore RepoSense AI →](https://github.com/Bhumi1107/RepoSense-AI)
